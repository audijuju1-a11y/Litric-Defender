## What was made clean

Both caches that could hide the reported failure were removed before the build:

  rm -rf fuzz/target
  rm -rf target/evidence/phase1/clean-cargo-home

The build then ran with:

  CARGO_HOME="$PWD/target/evidence/phase1/clean-cargo-home" bash fuzz/build.sh

The empty CARGO_HOME is the clean-checkout condition that previously failed with
"no matching package named `libfuzzer-sys`". The fixed runtime builder runs
`cargo fetch --locked` before its offline metadata lookup.
