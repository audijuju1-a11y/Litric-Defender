# B-origin — historical provenance records

This folder preserves the engineering records of the second code line that was
merged into Litric Defender (ClamAV-format import, signed database, real-time
logic, recovery vault). It exists for **provenance, ownership and licence
history**, not as current platform documentation.

The measurements in this folder were taken on the original Linux container in
which that code line was written. They are **not Windows evidence** and must not
be quoted as current performance. The merged tree is now Windows-only and runs
natively on Windows 11; current tests, detection results and benchmarks live in:

* `docs/WINDOWS_EVIDENCE.md`
* `docs/STATUS.md`
* `docs/BENCHMARKS.md`

Do not use this folder to justify a Linux build, a Wine runner or a
cross-platform support claim. The repository has none of those.
